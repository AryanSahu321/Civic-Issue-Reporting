### 🛠️ Backend Setup - Error Resolution Log

| Error Message / Problem | Error Kyun Aaya? (Reason) | Kaise Solve Kiya? (Solution) |
| :--- | :--- | :--- |
| **`ERESOLVE could not resolve` (NPM Install Error)** | NPM ka version checker bohot strict tha aur purane packages (`ts-jest`, `typescript`) ke versions aapas mein clash kar rahe the. | `npm install` command ke end mein **`--legacy-peer-deps`** flag lagaya. Isne strict checking bypass karke install complete kiya. |
| **VS Code Git Warning:** *"too many active changes... add node_modules to .gitignore?"* | `node_modules` folder mein hazaron (thousands) files hoti hain. Git un sabko track karne ki koshish kar raha tha jisse woh overload ho gaya. | Popup par **"Yes"** click kiya. Isne `.gitignore` file mein `node_modules` likh diya, jisse Git ne us folder ko ignore kar diya. |
| **`ECMAScript imports... cannot be written... under verbatimModuleSyntax`** | TypeScript ko pata nahi tha ki hum modern ES Modules use kar rahe hain, aur uski strict settings (verbatim) code ko block kar rahi thi. | 1. `package.json` mein `"type": "module"` add kiya. <br>2. `tsconfig.json` mein strictness/verbatim syntax ko hata diya/false kiya. |
| **`datasource property 'url' is no longer supported` (Prisma Error)** | Aap Prisma ka bilkul latest version (**v7.9.1**) use kar rahe the. Prisma 7 mein rules change ho gaye hain aur ab `schema.prisma` ke andar DB URL likhna mana hai. | `schema.prisma` file ke datasource block se `url = env("DATABASE_URL")` wali line ko **delete** kar diya. |
| **`Module '@prisma/client' has no exported member 'PrismaClient'`** | 1. Schema mein provider galat tha (`prisma-client-js` hona chahiye).<br>2. Generate hone ke baad VS Code ka cache (memory) purana code hi dekh raha tha. | 1. Schema correct karke dobara `npx prisma generate` chalaya.<br>2. VS Code mein **`Ctrl+Shift+P` -> Restart TS Server** kiya taaki cache refresh ho jaye. |
| **`Relative import paths need explicit file extensions...`** | Kyunki humne ES Modules (`"type": "module"`) enable kar diya tha, Node.js ka rule hai ki local files import karte waqt end mein extension batana zaroori hai. | `server.ts` mein import ko change karke `.js` laga diya: `import app from "./app.js";` |
| **`TypeError: Cannot read properties of undefined` (ts-node Crash)** | Latest Node.js (v24) aur modern ES Modules (`"type": "module"`) ke sath purana `ts-node` package compatible nahi tha aur run karne par crash ho gaya. | 1. `ts-node` ki jagah modern tool **`tsx`** install kiya (`npm install -D tsx`).<br>2. `package.json` mein dev script ko update karke `"dev": "tsx watch src/server.ts"` kar diya. |
